# Simulação Financeira — Sistema GVS Terceirizações

Projeto Integrador (Gestão e Governança de TI) — FATEC Indaiatuba, Grupo H.

Conteúdo: premissas, TCO e cenários de ROI (pessimista, esperado, otimista) da empresa de tecnologia e do cliente padrão (GVS).

- `planilha/Simulacao_Financeira_GVS.xlsx`: TCO da empresa e ROI (empresa e cliente) em 3 cenarios, com formulas ligadas as premissas (edite apenas as celulas azuis da aba Premissas)
